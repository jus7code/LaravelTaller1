# 📌 Nombre del proyecto

Mi Perfil Pro

## 📝 Descripción breve

Aplicación web desarrollada con Laravel y Blade que permite gestionar y visualizar un perfil profesional con secciones como perfil, intereses, habilidades y metas, ofreciendo una interfaz clara y organizada.

## 💻 Requisitos del sistema

* PHP 8.x o superior
* Composer
* Servidor web local (Laravel Sail, XAMPP, Laragon o similar)
* Navegador web moderno

## ⚙️ Instrucciones de instalación

1. Clonar el repositorio:
   git clone <url-del-repositorio>

2. Entrar al directorio del proyecto:
   cd mi-perfil

3. Instalar dependencias:
   composer install

4. Configurar variables de entorno:
   cp .env.example .env

5. Generar clave de aplicación:
   php artisan key:generate

## ▶️ Cómo ejecutar el proyecto

Ejecutar el servidor local:
php artisan serve

Abrir en el navegador:
http://localhost:8000
